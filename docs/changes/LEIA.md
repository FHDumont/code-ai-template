# Fragmentos de fase

> Pra que serve: um arquivo `F-xxx.md` por fase paralela, na branch dela, com as linhas que a integração consolida nos ledgers. A fase paralela não edita `CHANGELOG`, `ROADMAP`, `DECISOES`, débito nem `SETUP-HISTORICO`. Quem aplica e apaga é `scripts/integrar-fase.sh`. Forma e regras: `docs/reference/integracao.md` (R-003).
