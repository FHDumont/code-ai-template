# Fases ativas

> Pra que serve: um arquivo `F-xxx.md` por fase **paralela**, na branch dela, com o que ela reivindica (modelo em `templates/fase-ativa.md`). O `main` não acumula esses arquivos — a integração apaga o da fase ao entrar. Quem lista é `scripts/fases-ativas.sh`; branch `fase/*` sem registro (a fase solitária) reivindica o repo inteiro. Forma e regras: `docs/reference/integracao.md` (R-002).
