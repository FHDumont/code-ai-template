# Atritos — o contador do observador

> Pra que serve: o atrito que o agente encontra no método (regra esquecida, correção repetida do dono, hook que barrou o caminho óbvio, spec que divergiu de uma decisão já tomada) não se corrige em silêncio nem se perde: entra aqui, com o destino. A regra do observador está em `AGENTS.md` §Observador de atrito; quem registra são o `/fechar-fase` (entre a revisão e os docs) e o `/planejar-fase`. É ledger: a integração junta as linhas de duas fases (R-004).

**Como ler.** Uma linha por regra. `Fases` lista onde o atrito apareceu; duas fases ou mais = segunda ocorrência, e o destino deixa de ser `nada`: o agente **propõe o hook** (`AGENTS.md` §O loop: regra violada mais de uma vez é candidata a hook; o hook que não paga um risco medido não entra, e quem decide é o dono). `Destino`: `hook` · `skill` · `AGENTS.md` · `R-NNN` · `nada` (uma ocorrência ainda não pede nada).
