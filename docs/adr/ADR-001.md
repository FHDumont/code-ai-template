# ADR-001 — Canal de bots como add-on opcional do template

- **Status:** accepted
- **Data:** 2026-11-14
- **Fase:** F-metodo-v5

## Contexto

O Fernando usa este template em projetos com agente de código e, em paralelo, bots do Grok Bot (Marketing, Apps, Infraestrutura, Comercial, Empresa). No amplug o canal com o marketing já funciona: pasta fora do git, pedido e resposta em markdown, webhook que leva só o ponteiro, chave em arquivo 600 fora do repo (`video/scripts/amplug-canal-avisar`, F-089 e F-091). O time precisa do mesmo padrão em todo projeto derivado, sem obrigar bot em projeto que não tem.

## Decisão

O canal entra neste template como add-on opcional, no mesmo espírito de `examples/perfil-llm-agente.md`. Sem bot declarado na issue ou na spec, nada muda. Com bot, o contrato é o v1 de `docs/reference/canal.md`: vários bots, pasta `~/.canal/<projeto>/`, uma unidade de trabalho por fase ou issue, aviso só com ponteiro, chave fora do repo. A lista de quem trabalha numa fase é a seção `## Bots` da spec, herdada da issue de trabalho. Os scripts (`canal-avisar`, disparador) não entram nesta fase.

## Alternativas consideradas

- **Repositório novo só para o canal.** O método e o canal divergiriam, e cada projeto derivado teria dois lugares para copiar.
- **Copiar o layout de um bot só do amplug.** A pasta única `pedidos/` não diz qual bot responde, e o prefixo `AMPLUG_` não serve para outro projeto.
- **Bot obrigatório no núcleo do `AGENTS.md`.** Projeto sem Grok Bot passaria a carregar regra que não usa.

## Consequências

Projeto sem bot não muda o loop. Projeto com bot ganha issue, spec e pasta no mesmo formato, e o agente de código só consulta quem foi listado. O amplug não é migrado aqui: o script dele continua o dele até alguém apontar para o contrato v1. Até a F-metodo-v6 não há `canal-avisar` neste template — o arquivo no canal é o pedido, e quem responde pode ser o bot, um humano ou outro agente. Ação cara espera o dono; neste time, o dono é o Fernando. O teto diário e a janela de agrupamento são chaves do `bots.yaml` (o exemplo traz 40 e 60 s), não medição do amplug.

## Emendas

- ADR-002 (F-metodo-v6) — os scripts do canal saem da F-metodo-v6 e ficam na F-metodo-v7; o corpo acima não muda. Fase paralela não altera o contrato v1: a pasta do canal já é por id de fase.
